# Tiny LLM Playground

Chat playground for a tiny LLM built with [tiny-llm-template](https://github.com/your-username/tiny-llm-template).

The model was trained for next-token prediction and may not be optimized for
multi-turn dialogue; each message is sent as a fresh `### Instruction:` prompt.

Source: https://github.com/your-username/tiny-llm-template
